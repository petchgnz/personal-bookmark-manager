# transcript-writer

Maintain session records in `transcripts/codex_session_[n]_log.md`.

Each transcript must include:

- Goal or task assigned.
- User prompts and material commands or actions in chronological order.
- Code or logic created or changed.
- Errors and debugging steps.
- Final output.
- Date, session number, starting and ending commit when available, tools and model, files changed, verification commands and real outcomes, known limitations, and redaction notes.

Do not include hidden reasoning, platform-internal instructions, secrets, raw tokens, or credentials.
